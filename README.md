# Biblioteca Musical — pacotes

Pacotes opcionais baixados pelo app [Biblioteca Musical](https://github.com/HyakoV3/biblioteca-musical). Este repositório guarda **só** os pacotes de **sons gravados**; o app confere o tamanho e o SHA-256 de cada arquivo antes de instalar.

## Sons gravados

`sons-<sha8>.zip` (anexo do Release): 16 arquivos `<instrumento>-mp3.js` (notas MIDI 30 a 86, MP3 mono a 80 kbps), renderizados do banco **GeneralUser GS v2.0.3** de S. Christian Collins, sem reverb nem coro. O banco permite uso livre, inclusive comercial, e a modificação e redistribuição do banco e do seu empacotamento; veja [`LICENSE-GeneralUser-GS.txt`](LICENSE-GeneralUser-GS.txt). Site do autor: <http://www.schristiancollins.com>.

Instrumentos: drawbar_organ, alto_sax, bassoon, clarinet, flute, oboe, recorder, tenor_sax, french_horn, trombone, trumpet, tuba, cello, contrabass, viola, violin.

Conferir o download: `sha256sum -c SHA256SUMS`.
